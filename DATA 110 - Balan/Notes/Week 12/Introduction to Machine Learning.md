## What is Artificial Intelligence?

In the broadest sense, Artificial Intelligence (AI) applies advanced analysis and logic-based techniques to interpret events and to support and automate decisions and actions.

### Types of AI

**Generative AI**

- Systems that can create new content by learning from patterns in data

**Predictive AI**

- Systems based on machine learning models that are designed for specific tasks
- Includes classification, prediction, or decision making based on structured data

## Predictive AI

Predictive AI is characterized by:

- Designed to leverage historical data to perform specific prediction tasks efficiently
- Uses supervised and unsupervised machine learning algorithms
- Relies primarily on structured data
- Results in better decisions, cost savings, and increased profitability

## How it all fits together

The relationship between General Intelligence (GI), Artificial Intelligence (AI), Deep Learning (DL), and Machine Learning (ML):

- **AI** is a subset of computational systems designed to simulate intelligent behavior
- **Machine Learning** is a subset of AI focused on systems that learn from data
- **Deep Learning** is a subset of ML that uses neural networks with multiple layers

## Machine Learning Definition

> "Machine Learning is focused on building applications that learn from data and improve their accuracy over time without being explicitly programmed to do so." — IBM Think Blog

### The Father of Machine Learning

**Arthur Samuel** pioneered machine learning through his work on checkers-playing programs, demonstrating that computers could learn and improve through experience.

## Machine Learning Terminology

Key concepts in machine learning (from MIT Sloan School of Management):

- **Algorithm**: A set of rules or instructions given to an AI system to help it learn patterns from data
- **Model**: The output of a machine learning algorithm trained on data
- **Training Data**: The dataset used to teach a machine learning model
- **Features**: Individual measurable properties or characteristics used as input for models
- **Labels**: The output or target variable that the model is trying to predict
- **Supervised Learning**: Learning from labeled training data
- **Unsupervised Learning**: Finding patterns in unlabeled data
- **Overfitting**: When a model learns training data too well and fails to generalize to new data
- **Underfitting**: When a model is too simple to capture the underlying patterns in the data

## Machine Learning Process

### CRISP-DM Framework

The Cross-Industry Standard Process for Data Mining (CRISP-DM) includes:

1. **Business Understanding**
    
    - Define objectives and requirements from a business perspective
    - Convert business goals into data mining problem definitions
2. **Data Understanding**
    
    - Collect initial data
    - Explore data to identify quality issues and insights
    - Discover initial patterns
3. **Data Preparation**
    
    - Select, clean, and transform data
    - Construct final dataset for modeling
    - Address data quality issues
4. **Modeling**
    
    - Select and apply various modeling techniques
    - Calibrate model parameters for optimal results
    - May require returning to data preparation phase
5. **Evaluation**
    
    - Assess the model's quality and validity
    - Review process to ensure business objectives are met
    - Determine if model is ready for deployment
6. **Deployment**
    
    - Put model into production environment
    - Generate reports and integrate into workflows
    - Set up monitoring and maintenance processes

## Key Takeaways

- Always begin with the end in mind
    - What is the problem you are trying to solve?
    - How will you know if you are successful?
- Don't underestimate the "data preparation" phase
- Machine learning is an iterative process
- You're not done until the model is deployed
- Don't forget about monitoring and maintenance
