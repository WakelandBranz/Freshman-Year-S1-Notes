>**Cardinal Numbers**: Express "how many" - the size or quantity of a set (1, 2, 3...).

>**Ordinal Numbers**: Express position or order - first, second, third, etc.

> **Nominal Numbers:** Names in a data set

>**Natural Numbers (N)**: The counting numbers: 1, 2, 3, 4, ... Used for counting objects.
