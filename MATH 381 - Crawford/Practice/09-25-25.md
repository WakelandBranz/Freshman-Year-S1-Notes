##### 1.8 exercise #5 (1.8.5)
Prove that if $x, y \in \mathbb{R}$, then $x + y = min(x, y) + max(x, y)$

**-PF-**
Assume $x, y \in \mathbb{R}$.
We will solve this through proof by cases.
For case 1, let $x > y$.
For $x > y$, $min(x, y) + max(x, y) = y + x = x + y$.
So, if arbitrary number $x$ is greater than arbitrary number $y$ then $min(x, y) + max(x, y)$ is equivalent to $x + y$.
For case 2, let $x < y$.
For $x < y$, $min(x, y) + max (x, y) = x + y = x + y$.
So, if arbitrary number $x$ is less than arbitrary number $y$ then $min(x, y) + max(x, y)$ is equivalent to $x + y$.
For case 3, let $x = y$.
For $x = y$, $min(x, y) + max(x, y) = x + x = y + y = x + y$.
So, if arbitrary number $x$ is equal to arbitrary number $y$ then $min(x, y) + max(x, y)$ is equivalent to $x + y$.
Thus, if $x, y \in \mathbb{R}$, then $x + y = min(x, y) + max(x, y)$.
