
### 1. Prove that for integers $a, b,$ and $c$, if $a + b$ and $b + c$ are even, then $a + c$ is even.

Assume $a + b$ and $b + c$ are even.
WTS $a + c$ is even.
Since $a + b$ and $b + c$ are both even, we can know $a + b + b + c$ is also even.
Let there exist an integer $n$ s.t. $a + 2b + c = 2n$.
So, $a + c = 2n - 2b$.
Since $2n$ is even and $-2b$ is divisible by $2$,  $2n - 2b$ is even.
So, $a + c = 2n - 2b$ means that $a + c$ is even.
Thus $a + c$ is even.
