## Definitions

**Def. Relation:** A relation $R$ from a set $A$ to a set $B$ is a subset of $A \times B$. When we say a relation is "on" a set $A$, we mean it is a relation from $A$ to $A$, so $R \subseteq A \times A$.

---

## Properties of Relations

**Reflexive:** A relation $R$ on a set $A$ is reflexive if $(a, a) \in R$ for every element $a \in A$.

**Symmetric:** A relation $R$ on a set $A$ is symmetric if whenever $(a, b) \in R$, then $(b, a) \in R$.

**Antisymmetric:** A relation $R$ on a set $A$ is antisymmetric if whenever $(a, b) \in R$ and $(b, a) \in R$, then $a = b$.

**Transitive:** A relation $R$ on a set $A$ is transitive if whenever $(a, b) \in R$ and $(b, c) \in R$, then $(a, c) \in R$.

---

## Graph Representation

**Directed Graph Representation:** If $R$ is a relation on a set $A = \{a_1, \ldots, a_n\}$, we can represent $R$ as a directed graph (digraph) where:
- Each element of $A$ is represented as a vertex
- There is a directed edge from vertex $a_i$ to vertex $a_j$ if and only if $(a_i, a_j) \in R$

### Properties in Graph Representation

**Reflexive:** A relation $R$ is reflexive if and only if every vertex has a self-loop (an edge from the vertex to itself).

**Symmetric:** A relation $R$ is symmetric if and only if whenever there is an edge from vertex $a$ to vertex $b$, there is also an edge from vertex $b$ to vertex $a$. In other words, edges come in pairs with opposite directions (or we can think of them as undirected edges).

**Antisymmetric:** A relation $R$ is antisymmetric if and only if there are no pairs of vertices $a \neq b$ where both an edge from $a$ to $b$ and an edge from $b$ to $a$ exist. Self-loops are allowed.

**Transitive:** A relation $R$ is transitive if and only if whenever there is an edge from vertex $a$ to vertex $b$ and an edge from vertex $b$ to vertex $c$, there must also be an edge from vertex $a$ to vertex $c$.

---

### Graph Example

Consider the relation $R = \{(1,1), (1,2), (2,1), (2,2), (3,3)\}$ on the set $A = \{1, 2, 3\}$. 

**Graph representation:**
- Vertex 1 has a self-loop and edges to/from vertex 2
- Vertex 2 has a self-loop and edges to/from vertex 1  
- Vertex 3 has only a self-loop

**Properties:**
- **Reflexive:** Yes - every vertex (1, 2, and 3) has a self-loop
- **Symmetric:** Yes - the edges between 1 and 2 go in both directions
- **Antisymmetric:** No - vertices 1 and 2 have edges in both directions, but $1 \neq 2$
- **Transitive:** Yes - we can verify all paths of length 2 have a direct edge

## Examples

### Ex 1

What is the relation $R = {(a, b) \mid a \text{ divides } b}$ on the set $A = \{1, 2, 3, 4\}$.

We need to find all ordered pairs $(a, b)$ where $a$ divides $b$:

- 1 divides 1, 2, 3, 4: $(1,1), (1,2), (1,3), (1,4)$
- 2 divides 2, 4: $(2,2), (2,4)$
- 3 divides 3: $(3,3)$
- 4 divides 4: $(4,4)$

Therefore, $R = {(1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)}$

### Ex 2

Let $A$ be a set so that $|A| = n \in \mathbb{Z}^+$. Determine the number of possible relations that can be put on $A$.

A relation on $A$ is a subset of $A \times A$. Since $|A| = n$, we have $|A \times A| = n^2$. The number of subsets of a set with $n^2$ elements is $2^{n^2}$.

Therefore, there are $2^{n^2}$ possible relations on $A$.

Use this to determine the number of relations on the set ${a, b, c}$.

For the set ${a, b, c}$, we have $n = 3$, so the number of relations is $2^{3^2} = 2^9 = 512$.

### Ex 3

For any set $A$, which properties do the the relations $R = \emptyset$ and $R = A \times A$ satisfy.

**For $R = \emptyset$:**

- **Reflexive:** No. For $R$ to be reflexive, we need $(a, a) \in R$ for all $a \in A$. Since $R$ is empty, this fails (unless $A = \emptyset$).
- **Symmetric:** Yes (vacuously true). There are no pairs $(a, b) \in R$, so the condition is vacuously satisfied.
- **Antisymmetric:** Yes (vacuously true). There are no pairs $(a, b)$ and $(b, a)$ both in $R$ with $a \neq b$.
- **Transitive:** Yes (vacuously true). There are no pairs $(a, b)$ and $(b, c)$ both in $R$.

**For $R = A \times A$:**

- **Reflexive:** Yes. All pairs $(a, a)$ are in $A \times A$.
- **Symmetric:** Yes. If $(a, b) \in A \times A$, then $(b, a) \in A \times A$.
- **Antisymmetric:** No (unless $|A| \leq 1$). For any $a \neq b$ in $A$, both $(a, b)$ and $(b, a)$ are in $R$, but $a \neq b$.
- **Transitive:** Yes. If $(a, b) \in A \times A$ and $(b, c) \in A \times A$, then $(a, c) \in A \times A$.

### Ex 4

Given the following relations $R_1, \cdots, R_6$ on the set of integers, determine which relations are reflexive, symmetric, antisymmetric, or transitive. Be sure to prove your answers.

$R_1 = {(a, b) \mid a \leq b}$

- **Reflexive:** Yes. For any integer $a$, we have $a \leq a$, so $(a, a) \in R_1$.
- **Symmetric:** No. Take $a = 1, b = 2$. Then $1 \leq 2$, so $(1, 2) \in R_1$. But $2 \not\leq 1$, so $(2, 1) \notin R_1$.
- **Antisymmetric:** Yes. Suppose $(a, b) \in R_1$ and $(b, a) \in R_1$. Then $a \leq b$ and $b \leq a$, which implies $a = b$.
- **Transitive:** Yes. Suppose $(a, b) \in R_1$ and $(b, c) \in R_1$. Then $a \leq b$ and $b \leq c$, so $a \leq c$, meaning $(a, c) \in R_1$.

$R_2 = {(a, b) \mid a > b}$

- **Reflexive:** No. For any integer $a$, we have $a \not> a$, so $(a, a) \notin R_2$.
- **Symmetric:** No. If $a > b$, then $b < a$, so $b \not> a$. For example, $(2, 1) \in R_2$ but $(1, 2) \notin R_2$.
- **Antisymmetric:** Yes (vacuously). Suppose $(a, b) \in R_2$ and $(b, a) \in R_2$. Then $a > b$ and $b > a$, which is impossible. So the hypothesis is never satisfied.
- **Transitive:** Yes. Suppose $(a, b) \in R_2$ and $(b, c) \in R_2$. Then $a > b$ and $b > c$, so $a > c$, meaning $(a, c) \in R_2$.

$R_3 = {(a, b) \mid a = b \text{ or } a = -b}$

- **Reflexive:** Yes. For any integer $a$, we have $a = a$, so $(a, a) \in R_3$.
- **Symmetric:** Yes. Suppose $(a, b) \in R_3$. Then either $a = b$ or $a = -b$. If $a = b$, then $b = a$, so $(b, a) \in R_3$. If $a = -b$, then $b = -a$, so $(b, a) \in R_3$.
- **Antisymmetric:** No. Consider $a = 1$ and $b = -1$. Then $1 = -(-1)$, so $(1, -1) \in R_3$. Also, $-1 = -(1)$, so $(-1, 1) \in R_3$. But $1 \neq -1$.
- **Transitive:** Yes. Suppose $(a, b) \in R_3$ and $(b, c) \in R_3$. We have four cases:
    - If $a = b$ and $b = c$, then $a = c$, so $(a, c) \in R_3$.
    - If $a = b$ and $b = -c$, then $a = -c$, so $(a, c) \in R_3$.
    - If $a = -b$ and $b = c$, then $a = -c$, so $(a, c) \in R_3$.
    - If $a = -b$ and $b = -c$, then $a = c$, so $(a, c) \in R_3$.

$R_4 = {(a, b) \mid a = b}$

- **Reflexive:** Yes. For any integer $a$, we have $a = a$, so $(a, a) \in R_4$.
- **Symmetric:** Yes. If $(a, b) \in R_4$, then $a = b$, which implies $b = a$, so $(b, a) \in R_4$.
- **Antisymmetric:** Yes. If $(a, b) \in R_4$ and $(b, a) \in R_4$, then $a = b$ (by definition of $R_4$).
- **Transitive:** Yes. If $(a, b) \in R_4$ and $(b, c) \in R_4$, then $a = b$ and $b = c$, so $a = c$, meaning $(a, c) \in R_4$.

$R_5 = {(a, b) \mid a = 1 + b}$

- **Reflexive:** No. For any integer $a$, we have $a \neq 1 + a$, so $(a, a) \notin R_5$.
- **Symmetric:** No. If $(a, b) \in R_5$, then $a = 1 + b$, so $b = a - 1$. For $(b, a)$ to be in $R_5$, we'd need $b = 1 + a$, which means $a - 1 = 1 + a$, giving $-1 = 1$, a contradiction. For example, $(2, 1) \in R_5$ but $(1, 2) \notin R_5$.
- **Antisymmetric:** Yes (vacuously). If $(a, b) \in R_5$ and $(b, a) \in R_5$, then $a = 1 + b$ and $b = 1 + a$. Substituting: $a = 1 + (1 + a) = 2 + a$, which gives $0 = 2$, a contradiction. So the hypothesis is never satisfied.
- **Transitive:** No. Consider $(a, b) = (2, 1)$ and $(b, c) = (1, 0)$. Then $2 = 1 + 1$ and $1 = 1 + 0$, so both pairs are in $R_5$. For transitivity, we'd need $(2, 0) \in R_5$, which requires $2 = 1 + 0 = 1$, which is false.

$R_6 = {(a, b) \mid a + b \leq 3}$

- **Reflexive:** No. Consider $a = 5$. Then $5 + 5 = 10 \not\leq 3$, so $(5, 5) \notin R_6$.
- **Symmetric:** Yes. If $(a, b) \in R_6$, then $a + b \leq 3$. Since addition is commutative, $b + a = a + b \leq 3$, so $(b, a) \in R_6$.
- **Antisymmetric:** No. Consider $a = 0$ and $b = 1$. Then $0 + 1 = 1 \leq 3$, so $(0, 1) \in R_6$. Also, $1 + 0 = 1 \leq 3$, so $(1, 0) \in R_6$. But $0 \neq 1$.
- **Transitive:** No. Consider $(2, 1) \in R_6$ (since $2 + 1 = 3 \leq 3$) and $(1, 2) \in R_6$ (since $1 + 2 = 3 \leq 3$). For transitivity, we'd need $(2, 2) \in R_6$, which requires $2 + 2 = 4 \leq 3$, which is false.

## Matrix Representation

Relations may be represented in many different ways. You have already seen one, the "bubble" style we used to represent functions. We will study two other interesting ways. I will introduce one now and the other in class.

**Matrix Representation:** If $R$ is a relation from a set $A = {a_1, \cdots, a_n}$ to a set $B = {b_1, \cdots, b_m}$, construct a matrix called $M_R$ which has entries $m_{ij}$ in row $i$ and column $j$. The entries are decided as follows:

$$m_{ij} = \begin{cases} 1 & \text{if } (a_i, b_j) \in R \ 0 & \text{if } (a_i, b_j) \notin R \end{cases}$$

**Example:** If $A = {1, 2, 3}$ and $B = {a, b}$, consider the relation $R = {(2, a), (3, a), (1, b)}$. Then we would say the matrix representing the relation $R$ is

$$M_R = \begin{bmatrix} 0 & 1 \ 1 & 0 \ 1 & 0 \end{bmatrix}$$

### Ex 6

Let $R$ be a relation on the set $A$ and $|A| = n$. What could you say about the matrix representing $R$ if:

(a) the relation $R$ is reflexive?

If $R$ is reflexive, then $(a_i, a_i) \in R$ for all $i = 1, 2, \ldots, n$. This means $m_{ii} = 1$ for all $i$. Therefore, the main diagonal of $M_R$ consists entirely of 1's.

(b) the relation $R$ is symmetric?

If $R$ is symmetric, then whenever $(a_i, a_j) \in R$, we also have $(a_j, a_i) \in R$. This means if $m_{ij} = 1$, then $m_{ji} = 1$. Therefore, $M_R$ is a symmetric matrix, meaning $M_R = M_R^T$ (the matrix equals its transpose).

(c) the relation $R$ is antisymmetric?

If $R$ is antisymmetric, then whenever $(a_i, a_j) \in R$ and $(a_j, a_i) \in R$ with $i \neq j$, we must have $a_i = a_j$ (which contradicts $i \neq j$). This means that for $i \neq j$, we cannot have both $m_{ij} = 1$ and $m_{ji} = 1$. Therefore, if $m_{ij} = 1$ for $i \neq j$, then $m_{ji} = 0$. The diagonal entries can be anything (0 or 1).
