## Template for Proofs by Mathematical Induction:

1. Express the statement to be proved by defining the propositional function $P(n)$ and saying "For all integers $n \geq b$, $P(n)$."
    
2. Write the words "Base Step" or "Base Case". Then show that $P(b)$ is true.
    
3. Write "Inductive Step" and state clearly the inductive hypothesis. That is "Assume that $P(k)$ is true for an arbitrary fixed integer $k \geq b$."
    
4. Prove the statement $P(k + 1)$ using the assumption $P(k)$. (It is often helpful to clearly write what $P(k + 1)$ is as scratch work.) During this step you will use the fact that $P(k)$ is true. When you do so, you should explicitly say "... by the induction hypothesis."
    
5. Conclude the inductive step clearly.
    
6. State the conclusion: "By Mathematical Induction, $P(n)$ is true for all integers $n$ with $n \geq b$."
    

---

## Example 1

Show that if $n$ is a positive integer then $1 + 2 + \cdots + n = \frac{n(n+1)}{2}$.

**(1) Define $P(n)$:** WTS for all $n \geq 1$, $n \in \mathbb{Z}$, $1 + 2 + \dots + n = \frac{n(n+1)}{2}$

**Proof.**

**(2) Base Step:** $1 = \frac{1(1+1)}{2}$

**(3) Inductive Step:** Assume that $1 + 2 + \dots + k = \frac{k(k + 1)}{2}$, for an arbitrary fixed integer $k \geq 1$.

**(4) Prove $P(k + 1)$ using the inductive hypothesis:**

*Scratch Work*
$1 + 2 + 3 + \dots + k + (k + 1) = \frac{(k + 1)[(k + 1) + 1]}{2}$

**(5) Conclude the inductive step:**
By the inductive step, $1 + 2 + 3 + \dots + k = \frac{k(k+1)}{2}$
$\to 1 + 2 + 3 + \dots + k + (k + 1) = \frac{k(k+1)}{2} + (k + 1) = (k + 1)\left( \frac{k}{2} + 1 \right) = (k + 1) \frac{(k + 2)}{2} = \frac{(k +1)[(k + 1) + 1]}{2}$

**(6) Conclude the proof:** By Mathematical Induction, $1 + 2 + \dots + n = \frac{n(n + 1)}{2} \forall n \geq 1 \in \mathbb{Z}$
