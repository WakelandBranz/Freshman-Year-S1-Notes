## Definitions

### **Def. Set:** A *set* $S$ is an unordered collection of things called *elements*. We say a set *contains* its elements, and write $a \in S$. We write $a \not \in S$, if $a$ is not an element of $S$.

### **Describing Sets**

#### **Rosters:** $\{Bob, Matt, Joe\}$, $\{..., -3, -2, -1, 0 , 1, 2, 3, ...\}$ - Just an array-like list in curly braces.

- $[0, 1) = \{x \in \mathbb{R} \mid 0 \leq x < 1\}$ 
- $[a, b] = \{x \mid a \leq x \leq b\}$

	- $(a, b)$ - Open interval
	- $[a, b]$ - Closed interval
### **Often Used Sets:**

- $\mathbb{N} = \{1, 2, 3, \ldots\}$ the set of natural numbers (what you count with)
- $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$ the set of integers
- $\mathbb{Z}^+ = \{1, 2, 3, \ldots\}$ the set of positive integers
- $\mathbb{Q} = \left\{\frac{a}{b} \mid a, b \in \mathbb{Z} \text{ and } b \neq 0\right\}$ the set of rational numbers
- $\mathbb{Q}^+ = \left\{\frac{a}{b} \mid a, b \in \mathbb{Z} \text{ and } b \neq 0 \text{ and } \frac{a}{b} > 0\right\}$ the set of positive rational numbers
- $\mathbb{R}$ the set of real numbers
- $\mathbb{R}^+$ the set of positive real numbers
- $\mathbb{C}$ the set of complex numbers

### **Def. The Empty Set:** A set that has no elements. can be represented as $\emptyset$ or $\{\hspace{2mm}\}$.

Think of the empty set as a folder that is empty.
##### **Example**
- $\{x \in \mathbb{Z} \mid 0 < x < 1\} = \emptyset$

### **Def. Singleton Sets:** Set with exactly one element. Can be $\{\emptyset\}$ but $\{\emptyset\} \neq \emptyset$

Think of the $\{\emptyset\}$ as a folder containing the folder that is empty.
##### **Example**
 - $\{\{x \in \mathbb{Z} \mid 0 < x < \frac{1}{n}\} \mid n \in \mathbb{Z^+}\} = \{\emptyset\}$

## SIMPLE EXPLANATION

### Subset

A **subset** is like a smaller group that fits completely inside a larger group. If every person in group A is also in group B, then A is a subset of B.

**Example:** If $A = \{\text{cats, dogs}\}$ and $B = \{\text{cats, dogs, birds}\}$, then $A$ is a subset of $B$ because all animals in $A$ are also in $B$.

### Superset

A **superset** is just the opposite - it's the larger group that contains the smaller one. If B contains all the elements of A (and maybe more), then B is a superset of A.

**Example:** Using the same sets above, B = {cats, dogs, birds} is a superset of A = {cats, dogs} because B contains everything A has, plus more.

Think of it like Russian nesting dolls - the smaller doll (subset) fits completely inside the larger doll (superset).

### **Def. Finite Set:** If $\exists n \in \mathbb{Z}_{\geq 0}$ such that the number of elements in the set $A$ is n, then we say $A$ is a finite set. Else, we say $A$ is an infinite set.

Essentially, if there exists a number greater than 0 that we know of and is equivalent to the number of elements $A$, then it is a finite set.

#### Ex.
$|A| = n$ or #$A = n$. 
Cardinality - "size".
Cardinality is the number of elements in a set

### **Def. Power Set:** Given a set $A$, the power set of $A$, which we denoted $\mathcal{P(A)}$, and defined as $\mathcal{P(A)}:= \{ x \mid x \subset A\}$ i.e. $\mathcal{(P(A)}$ is the set of all subsets of $A$.
