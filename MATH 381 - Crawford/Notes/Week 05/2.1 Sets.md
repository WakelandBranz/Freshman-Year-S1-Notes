## Definitions

### **Def. Set:** A *set* $S$ is an unordered collection of things called *elements*. We say a set *contains* its elements, and write $a \in S$. We write $a \not \in S$, if $a$ is not an element of $S$.

### **Describing Sets**

#### **Rosters:** $\{Bob, Matt, Joe\}$, $\{..., -3, -2, -1, 0 , 1, 2, 3, ...\}$ - Just an array-like list in curly braces.

#### **Set Builder Notation:** $S = \{\frac{a}{b} | a, b \in \mathbb{Z}, b \neq 0\} = \mathbb{Q}$ (rational numbers)

##### Further examples:
- ***ODDS:***
	- $\{x \in \mathbb{Z}| \text{x is odd}\}$
	- $\{x \in \mathbb{R}| \text{x is an odd integer} \}$
	- $\{x|\exists k \in \mathbb{Z}|x = 2k + 1\}$
#### **Intervals:** 
- $[0, 1) = \{x \in \mathbb{R}| 0 \leq x < 1\}$ 
- $[a, b] = \{x | a \leq x \leq b\}$
- $[a, b) = \{x | a \leq x < b\}$
- $(a, b] = \{x | a < x \leq b\}$
- $(a, b) = \{x | a < x < b\}$
	- $(a, b)$ - Open interval
	- $[a, b]$ - Closed interval
### **Often Used Sets:**

- **N** = {0, 1, 2, 3, · · · } the set of natural numbers
- **Z** = {· · · , −2, −1, 0, 1, 2, · · · } the set of integers
- **Z⁺** = {1, 2, 3, · · · } the set of positive integers
- **Q** = {a/b | a, b ∈ Z and b ≠ 0} the set of rational numbers
- **Q⁺** = {a/b | a, b ∈ Z and b ≠ 0 and a/b > 0} the set of positive rational numbers
- **R** the set of real numbers
- **R⁺** the set of positive real numbers
- **C** the set of complex numbers

### **Def. The Empty Set:** A set that has no elements. can be represented as $\emptyset$ or $\{\hspace{2mm}\}$.

### **Def. Singleton Sets:** The single element of the singleton set is  $\{\emptyset\}$
