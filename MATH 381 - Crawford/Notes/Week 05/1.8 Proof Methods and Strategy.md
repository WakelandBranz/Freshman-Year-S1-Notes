## 1. Exhaustive Proof

### Definition: A proof proving a theorem that can be proved by examining a relatively small number of examples. They proceed by exhausting all possibilities.

### When to use:

### Example Problem:

**Statement to prove:** if n is a positive integer with $n \leq 4$, then $(n+1)^3 \geq 3^n$.

===-PF-===
We do an exhaustive proof and show the statement is true for n = 1, 2, 3, 4.

**Method:** Check all possible cases

- For n = 1: $(1 + 1)^3 = 8 \geq 3^1 = 3$ is true.
- For n = 2: $(2 + 1)^3 = 27 \geq 3^2 = 9$ is true.
- For n = 3: $(3 + 1)^3 = 64 \geq 3^3 = 27$ is true.
- For n = 4: $(4 + 1)^3 = 125 \geq 3^4 = 81$ is true.
