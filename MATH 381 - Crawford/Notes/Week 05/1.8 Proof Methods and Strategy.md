## 1. Exhaustive Proof

### Definition: A proof proving a theorem that can be proved by examining a relatively small number of examples. They proceed by exhausting all possibilities.

### When to use:

### Example Problem:

**Statement to prove:** if n is a positive integer with $n \leq 4$, then $(n+1)^3 \geq 3^n$.

===-PF-===
We do an exhaustive proof and show the statement is true for n = 1, 2, 3, 4.

**Method:** Check all possible cases

- For n = 1: $(1 + 1)^3 = 8 \geq 3^1 = 3$ is true.
- For n = 2: $(2 + 1)^3 = 27 \geq 3^2 = 9$ is true.
- For n = 3: $(3 + 1)^3 = 64 \geq 3^3 = 27$ is true.
- For n = 4: $(4 + 1)^3 = 125 \geq 3^4 = 81$ is true.

## 2. Proof by Cases

### Definition: We split the "domain" of the hypothesis into special interest cases. ***We must cover every possible case!***

---

### Use cases:
- Proof by cases is typically used when you're stuck staring at a problem and thinking "I have no idea how to even start this."
- If you realize that what's true in one situation might not apply the same way in another situation, you probably need to split things up.
- Sometimes when you know you're dealing with a particular type of situation, you suddenly have extra information or tools that make the problem easier.
- **General problem:** "Prove all vehicles can transport people" (This feels overwhelming)
- **Specific cases:**
    - Cars → You can talk about engines, roads, seats
    - Boats → You can talk about water, floating, navigation
    - Planes → You can talk about wings, air pressure, flight

Each case gives you specific details that make the proof manageable.

## Real-World Analogy

Think of it like explaining why "everyone in your office building can get to the first floor":

- **If you're stuck on the general proof:** You might not know where to start
- **Breaking into cases helps:**
    - People on floors 2-10 → Use the elevator or stairs
    - People already on floor 1 → They're already there
    - People in the basement → Use the basement stairs

Each case gives you concrete, specific ways to approach the problem.

**Bottom line:** Use proof by cases when the general problem feels impossible, but specific situations give you the extra information you need to make progress.

### Example 1: Integer Proof

**Statement to prove:** Prove that if $n$ is an integer, $n^2 \geq n$. 

**Cases to consider:**

- **Case 1:** n < 0 (negative integers)
    - Assumption: $n^2 \geq n$
    - Reasoning: Since negative numbers become positive when squared, $n^2$ will always be greater than $n$ since $n^2$ will be positive and $n$ will be negative. 
    - Conclusion: $n^2 \geq n$
- **Case 2:** n > 0 (positive integers)
    - Assumption: $n^2 \geq n$
    - Reasoning: Since $n$ is always positive, $n^2$ will be equal to $n$ when $n = 1$ and greater than $n$ when $n > 1$ since any positive integer greater than 1 will be larger than the original positive integer after it is squared.
    - Conclusion: $n^2 \geq n$
- **Case 3:** n = 0
    - Assumption: $n^2 = n$
    - Reasoning: Squaring 0 still equals 0, so $n^2$ and $n$ will both equal 0 thus making them equivalent and still making the statement $n^2 \geq n$ valid.
    - Conclusion: $n^2 \geq n$
