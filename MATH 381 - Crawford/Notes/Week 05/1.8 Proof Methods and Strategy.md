## 1. Exhaustive Proof

### Definition: A proof proving a theorem that can be proved by examining a relatively small number of examples. They proceed by exhausting all possibilities.

### When to use:

### Example Problem:

**Statement to prove:** If n is a positive integer with $n \leq 4$, then $(n+1)^3 \geq 3^n$.

===-PF-===
We do an exhaustive proof and show the statement is true for n = 1, 2, 3, 4.

**Method:** Check all possible cases... since there are quite literally only 4 positive integers less than or equal to 4 you can just check those specifically.

- For n = 1: $(1 + 1)^3 = 8 \geq 3^1 = 3$ is true.
- For n = 2: $(2 + 1)^3 = 27 \geq 3^2 = 9$ is true.
- For n = 3: $(3 + 1)^3 = 64 \geq 3^3 = 27$ is true.
- For n = 4: $(4 + 1)^3 = 125 \geq 3^4 = 81$ is true.

## 2. [Proof by Cases](obsidian://open?vault=UNC-FreshmanS1Notes&file=MATH%20381%20-%20Crawford%2FNotes%2FWeek%2005%2FProof%20by%20Cases%20Side%20Note)

### Definition: We split the "domain" of the hypothesis into special interest cases. ***We must cover every possible case!***

### Example 1: Integer Proof

**Statement to prove:** Prove that if $n$ is an integer, $n^2 \geq n$. 

**Cases to consider:**

- **Case 1:** n < 0 (negative integers)
    - Assumption: $n^2 \geq n$
    - Reasoning: Since negative numbers become positive when squared, $n^2$ will always be greater than $n$ since $n^2$ will be positive and $n$ will be negative. 
    - Conclusion: $n^2 \geq n$
- **Case 2:** n > 0 (positive integers)
    - Assumption: $n^2 \geq n$
    - Reasoning: Since $n$ is always positive, $n^2$ will be equal to $n$ when $n = 1$ and greater than $n$ when $n > 1$ since any positive integer greater than 1 will be larger than the original positive integer after it is squared. In non-retarded terms, $n * n \geq 1 * n$.
    - Conclusion: $n^2 \geq n$
- **Case 3:** n = 0
    - Assumption: $n^2 = n$
    - Reasoning: Squaring 0 still equals 0, so $n^2$ and $n$ will both equal 0 thus making them equivalent and still making the statement $n^2 \geq n$ valid.
    - Conclusion: $n^2 \geq n$

## 3. Without Loss of Generality (WLOG)

### Purpose: To reduce the number of cases by noticing symmetries

### How it works:

##### Example: Show $\forall x,y \in \mathbb{R}, |xy| = |x| * |y|$

Instead of proving 4 separate cases for $|xy| = |x||y|$, we can use WLOG to reduce to:

- **Case 1:** $x \leq 0, y \leq 0$
	- $|xy| = xy = (-x) * (-y) = |x| * |y|$
- **Case 2:** $x \leq 0, y > 0$
	- $|xy| = -(xy) = (-x) * y = |x| * |y|$
- **Case 3:** $x > 0, y \leq 0$
	- $|xy| = -(xy) = x * (-y) = |x| * |y|$
		- WLOG, we may assume $x \leq 0$ & $y > 0$ (to cover cases 2 & 3.)
- **Case 4:** $x > 0, y > 0$
	- $|xy| = xy = x * y = |x| * |y|$
