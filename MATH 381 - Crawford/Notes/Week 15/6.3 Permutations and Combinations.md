### Definitions
**Def. Permutation:** A permutation of a set of distinct objects is an ordered arrangement of the objects

**Def. Combination:** A combination of a set of distinct objects is an unordered arrangement of the objects.
 -  ===Note=== only interesting when talking about subsets of a set

**Def. r-Permutation:** An ordered arrangement of $r$ elements from a set of $n$ distinct elements is called an $r$-permutation.

**Def. r-Combination:** An unordered selection of $r$ elements from a set of $n$ distinct elements is called an $r$-combination.

### Theorems

**Thm:** If $n$ is a positive integer, and $r$ is an integer $1 \leq r \leq n$, then there are $$P(n, r) = n(n-1)(n-2)\cdots(n-r+1) = \frac{n!}{(n-r)!}$$ $r$-Permutations of a set with $n$ elements. (referring to the previous formula!)

**Thm:** The number of $r$-combinations of a set with $n$ elements, where $n \geq 0$ and $1 \leq r \leq n$, is $$C(n, r) = \binom{n}{r} = \frac{n!}{r!(n-r)!}$$
### Corollary $\leftarrow$ important!!!

$C(n, r) = \frac{P(n, r)}{r!} \leftrightarrow r!C(n, r) = P(n, r)$

### Examples

**Ex 1.** If $S = {1, 2, 3}$, how many 2-permutations, 3-permutations and 3-combinations are there?

- 2-permutations: $P(3,2) = 3 \cdot 2 = \boxed{6}$ — these are $(1,2), (2,1), (1,3), (3,1), (2,3), (3,2)$
- 3-permutations: $P(3,3) = 3! = \boxed{6}$
- 3-combinations: $C(3,3) = \boxed{1}$ — the only one is ${1, 2, 3}$

**Ex 2.** If 100 people enter a contest, how many ways can we choose 1st, 2nd, and 3rd place?

- Order matters, so $P(100, 3) = 100 \cdot 99 \cdot 98 = \boxed{970{,}200}$

**Ex 3.** A salesperson must visit 8 cities. The first is specified but they may visit the other 7 in any order. How many routes could they create?

- Arrange remaining 7 cities: $7! = \boxed{5{,}040}$ routes

**Ex 4.** How many permutations can you make of ABCDEFGH with ABC remaining together and in the same order?

- Treat "ABC" as a single block. Now arrange 6 objects (the block + D, E, F, G, H): $6! = \boxed{720}$

**Ex 5.** How many different committees of 3 may be formed from a group of 5?

- Order doesn't matter: $C(5,3) = \frac{5!}{3! \cdot 2!} = \boxed{10}$

**Ex 6.** How many different 5 card poker hands can be dealt from a standard 52 card deck? How many ways are there to select 47 cards?

- 5-card hands: $C(52, 5) = \frac{52!}{5! \cdot 47!} = \boxed{2{,}598{,}960}$
- 47-card selections: $C(52, 47) = C(52, 5) = \boxed{2{,}598{,}960}$

### Corollary

**Cor:** For $n, r \in \mathbb{Z}$ with $0 \leq r \leq n$, $$C(n, r) = C(n, n - r)$$ _Proof._ Choosing $r$ elements to include is equivalent to choosing $n - r$ elements to exclude.

**Ex 7.** Suppose 9 math faculty and 11 comp sci faculty can be put onto a 7 person committee that needs to have 3 math and 4 comp sci faculty on it. How many committees can be formed?

- Choose 3 from 9 math AND 4 from 11 CS: $C(9,3) \cdot C(11,4) = 84 \cdot 330 = \boxed{27{,}720}$
