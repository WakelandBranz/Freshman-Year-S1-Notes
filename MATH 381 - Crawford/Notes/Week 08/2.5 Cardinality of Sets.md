## The Continuum Hypothesis

It is a fact that P(ℤ⁺) has the same cardinality as ℝ. Call this number ζ. It is also a fact (proven by Cantor) that the cardinality of a set is always smaller than the cardinality of its power set, i.e. |A| < |P(A)|.

This leads to the fact that ℵ₀ = |ℤ⁺| < |P(ℤ⁺)| = ζ.

The question then becomes ... is there anything in between?

The current hypothesis is that there is no set A so that ℵ₀ < |A| < ζ.
