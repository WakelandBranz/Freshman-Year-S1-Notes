## The Continuum Hypothesis

It is a fact that $\mathcal{P}(\mathbb{Z}^+)$ has the same cardinality as $\mathbb{R}$. Call this number $\zeta$. It is also a fact (proven by Cantor) that the cardinality of a set is always smaller than the cardinality of its power set, i.e. $|A| < |\mathcal{P}(A)|$.

This leads to the fact that $\aleph_0 = |\mathbb{Z}^+| < |\mathcal{P}(\mathbb{Z}^+)| = \zeta$.

The question then becomes ... is there anything in between?

The current hypothesis is that there is no set $A$ so that $\aleph_0 < |A| < \zeta$.
