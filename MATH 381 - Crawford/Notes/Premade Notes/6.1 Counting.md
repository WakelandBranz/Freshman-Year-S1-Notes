## Def. Product Rule:

## Ex 1

How many different strings of 1's and 0's are there of length 8?

## Ex 2

How many functions are there from a set with $m$ elements to a set with $n$ elements?

## Ex 3

How many injective functions are there from a set with $m$ elements to a set with $n$ elements?

## Def. Sum Rule:

## Ex 4

A computer language requires variables be names using either 1 or 2 alphanumeric characters, where capitalization does not matter, and the first character must be a letter. How many different variables can be made?

## Ex 5

A password must be chosen using between 6 and 8 characters which are all uppercase letters or a digit 0 - 9. If each password must contain at least one digit, how many passwords can be made?

## Def. Subtraction Rule:

## Ex 6

How many strings of 1's and 0's of length 8 can be made which start with a 1 OR end with 00?

## Def. Division Rule:

## Ex 7

How many ways can we seat 4 people around a table that has 4 chairs?
