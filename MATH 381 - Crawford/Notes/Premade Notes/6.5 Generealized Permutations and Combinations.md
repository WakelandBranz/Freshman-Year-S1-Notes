**Recall:** An r-permutation of n objects can be done in $P(r, n) = \frac{n!}{(n-r)!}$ ways.

What if we allow some objects to be used more than once?

---

### Ex 1

How many ways can we make a string of 4 letters?

---

**Theorem:** There are $n^r$ r-permutations on n objects with repetition allowed.

### Ex 3

How many ways can you select five bills from a cash box which has 1, 2, 5, 10, and 20 dollar bills? Assume that the order chosen does not matter, the bills are indistinguishable aside from tender amount, and there are at least 5 of each bill.

---

**Theorem:** There are $\binom{n+r-1}{r} = \binom{n+r-1}{n-1}$ r-combinations from a set with n elements with repetition allowed.
