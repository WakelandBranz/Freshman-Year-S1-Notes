
### Definition

**Nested Quantifiers** occur when: One quantifier is within the scope of another

---

## Example 1: Truth Value Analysis

**Given:**

- Propositional function $Q(x) = \exists y P(x,y)$
- Where P(x, y) is the statement: x + y = 0

**Determine the truth value of each nested quantifier:**

### (1) $\forall x \forall yP(x,y)$
 - False
### (2) $\forall x \exists yP(x,y)$
 - True
### (3) $\exists x \forall yP(x,y)$
 - False
### (4) $\exists x \exists yP(x,y)$
 - True

## Example 2: Comparing Quantifier Order

**Given:** Q(x, y) is the statement x + y = 0

### Explain the difference between ∃x∀yQ(x, y) and ∀x∃yQ(x, y):

#### ∃x∀yQ(x, y)

There exists a value x for which all values of y are true when inputted into Q(x, y)
#### ∀x∃yQ(x, y)

For every value of x there is a value of y that results in Q(x, y) being true

### Key Difference:

One value of x for all values of y vs all values of x each has one value of y.
